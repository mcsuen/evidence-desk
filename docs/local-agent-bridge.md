# 本机 Agent 宿主

PITR 调用已安装和登录的官方 Codex / Claude Code CLI。运行固定提供方、CLI 版本、认证方式、连接指纹、模型与推理选项；变化不会被静默套用到旧会话。

宿主依赖 `RuntimeContext`，只有运行目录、主库路径用于隔离探测和 Agent 调用日志写入。研究写入通过受控工具服务，不通过旧 Desk 或候选重放目录。

macOS Seatbelt 约束本机 CLI 与其 shell 子进程：业务库、其他任务、无关临时目录不可读写；个人指令、插件、技能和 hooks 被隐藏。仅开放本次 scratch、原生认证及必要发行包文件。沙箱启动前实际检查主库读取、其他目录读写与直接网络连接均被拒绝。

出站只有能力服务端口和每次调用的模型网关。网关精确允许当前提供方及用户设置的 HTTPS 模型/认证主机，拒绝普通网页、无关子域和任意端口；关闭调用会关闭隧道。网页材料必须走 `source.discover/fetch`，再由服务核对主体与时点。历史研究不会获得公开检索或获取能力。

工具请求先校验角色、输入修订、run 代次、有效租约与范围，再检查幂等缓存。网络/PDF 长操作在事务外完成，写入时重验边界；缓存不继承已取消或已失效的权限。

取消会撤销能力并终止进程组；宿主崩溃时守护进程回收子进程。提供方队列定期续租，重启后可由新代次接管。原生会话、检查点与固定对象共同支持继续执行；正式提交必须来自当前代次。

真实双宿主验收脚本分别覆盖官方 PDD 原件研究，以及取消、工具服务中断、预算部分交付、继续和独立复核。模拟运行只出现在隔离测试夹具中，界面和产物明确标记为测试。

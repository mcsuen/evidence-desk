# 研究、报告修订与导出

创建问题时选择主体（可多选）、期间、原件版本、研究深度和宿主。只登记公司名称与域名会显示“人工登记”；官方目录提供证券识别线索，仍需明确选择，不代表企业所有陈述已核验。

七类方法包为问题界定、原件读取、财报变化、公司/产业尽调、估值、写作和独立复核。按需加载的包内容、摘要、版本、选择理由随执行固定。PDD 等企业阅读特例位于带来源的参考包；参考包不能充当本次证据。

交互、标准、深度提供不同的活动时间和工具调用预算，保留 10% 收尾额度。范围、工具请求 Schema 与剩余额度可通过执行详情追踪。尚未取得足够成功样本时预算明确标为暂定；按 [评测规则](evaluation.md) 校准，不伪造成本或费用。

预算耗尽会保存部分成果和检查点。取消、失败或部分交付后可以显式继续并增加预算；输入改变则保存新输入修订并新建执行。正式内容不能来自失效租约、过时代次或旧输入提交。

## 阅读与修订

点击正文、表格或图表数值可查看原件锚点、计算依赖及当前有效性。PDF 按需加载，来源修订和页码固定。窄屏使用底部证据面板，关闭后焦点返回原数字。

“修订报告”支持改标题、章节、段落、表格与图表标签，并选择已登记的数值和引用。编辑器的引用标记对应准确版本，不能填入未经解析的金额。更改原始数值或研究证据应先补充材料继续研究，再使用新对象写报告。

保存新修订时提供理由和预期版本，重新做内容检查并安排独立复核。可以比较前一修订，切换历史正文和历史导出。检查失败时先修正问题；服务或模型临时不可用可在维护页重试该报告的复核。

来源更正/撤回之后，“今日”提示受影响结果。原正文不被当前提示改写；在同一研究补充新来源，移除无效旧版本，从新输入继续。旧文件仍可以下载并保持摘要不变。

## Word

Word 与网页消费同一报告，不另行摘要。标题、正文、表格、引用书签、页眉页脚以及柱形/折线图均为原生内容；图表附可编辑工作簿。默认 Letter，可改 A4。中文字体由项目安装并在系统注册；导出必须通过结构核验、PDF 转换和逐页光栅化。运行检查不能代替人工页图检查，已渲染 PDF 可从报告页打开。

导出失败只重试导出任务。导出时的报告、检查和交付状态固定；后续复核发生改变，可请求新的产物，旧文件不覆盖。Word 允许任意编辑，本轮不回传站内。

扫描 PDF 没有文本层时可查看页图，但不能凭空创建与原文不符的文字锚点；应提供可核查文本或保留缺项。独立复核无法完成时显示“不可用/错误”，不显示通过。

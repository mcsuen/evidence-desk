# 公司与产业尽调

围绕商业机制和竞争解释研究：客户为什么购买、替代方案、供需约束、定价、成本与资本投入。先核对主体身份与交易关系，名称相似不能串主体。

关系判断记录双方、关系类型、成熟度及原文语义依据。表达“计划”“签约”“正在供货”“终止”不同；官方公告也可能只是计划。转载只算同一来源。关系存在与经济意义分别论证。

构造竞争解释，优先找区分性证据，保留不支持主结论的材料。数量规模、持续时间和依赖程度缺披露时明确留白。第三方预测不写成公司实际，行业经验不写成特定公司的事实。

把能持续跟踪的命题写为 assertion.propose；每项有支持、反证、替代解释、限制和下一验证点。真正互相依赖的判断用 depends_on，避免把共享一篇材料的判断无故绑在一起。

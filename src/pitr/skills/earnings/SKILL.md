# 财报与经营变化

建立同主体、同期间长度、同币种、同会计和股数口径的数据面板。先报告经营变化再解释原因：收入、业务结构、利润、费用、现金及营运资本，视问题选择，不能机械补齐不存在的披露。

同比、环比、利润率与百分点变动由计算工具生成。累计转单季必须是同年度相邻累计口径；同比需要可比期间。股数与 ADS 换算只能用有原件支持的比例，不内置公司特例。

驱动解释分别标识管理层陈述、可观测事实、推论与未证实假说。检查量价、业务组合、费用节奏、一次性项目和现金兑现之间是否有足够材料；缺少分拆时不能把相关当成因果。

至少说明一项可能推翻主解释的证据，以及下一期可核查指标。报告给出判断变化、可持续性、模型影响和未决问题，不用冗长指标清单代替答案。

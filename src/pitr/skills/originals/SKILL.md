# 原件读取与冲突处理

读取原件块目录再读必要的完整页面；复杂表格同时读取 source.tables 和 source.page。区分文本提取、表格提取和实际目视检查；不把成功渲染当成已看懂页面。

证据锚点必须逐字匹配，保留页码和列上下文。数值同时引用原值、单位、期间和会计口径依据；先 value.bind，再 value.calculate。解析正确不等于绑定了正确主体或正确列。

逐项核对原值、负号、括号、千／百万／亿、人民币／美元、普通股／ADS、GAAP／调整后、单季／累计、实际／指引／共识。数值出现多次时指定准确位置。不得用假设接口绕过原值检查。空白、破折号和不存在的项目保留缺项，不填零。

转载、同源报道和新闻聚合不能当成独立确认。使用 origin_group、原始链接、日期与引文识别共同来源；来源等级与命题真假分别判断。冲突保留双方证据、冲突口径与待澄清问题，不能简单投票。

历史时点严格使用快照，可得时间不等于事件时间、文档标题日期或今天的网页发布时间。

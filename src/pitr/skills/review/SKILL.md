# 独立质询与复核

从固定报告与原件出发，独立推导，不复用研究者的会话。优先检查会改变结论的错误：串主体、列与期间错误、单位、负号、ADS、会计口径、累计、实际与预测混淆、转载重复确认、关系语义、因果与估值假设。

逐项核对核心判断与数值在原件中的真实含义，计算记录只是确定性证据，不能代替阅读表头。检查主结论是否忽略反证、偷换范围或超过来源支持。

输出明确的 pass、revise 或 blocked，记录实际检查的判断与证据。发现问题给出可定位对象、原件依据及最小修正；材料不足用 blocked，不许凭感觉通过。不把 official、工具退出成功或文件存在当成真实性证明。

检查成本按风险决定。纯原文定位不强制完整模型复核；核心判断、模型和材料冲突必须复核。没有执行的检查保留未执行状态，不自动变成通过。

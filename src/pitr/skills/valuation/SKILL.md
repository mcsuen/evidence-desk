# 预测与估值

仅在问题需要时建模。分别标识实际披露、公司指引、卖方预测、市场共识与自有假设；每项假设有来源或推导、适用范围和限制。不得从新闻评分直接赋予模型可信度。

使用 value.assume 记录假设、value.calculate 记录计算、model.propose 固定模型。拆开增长、利润率、再投资、资本成本及终值的经济逻辑；财报口径、币种、普通股／ADS 必须一致。

给出基准及能改变判断的情景或敏感性，不用单点估值掩盖不确定性。无法由已登记计算规则可靠表达的复杂公式，应明确列为未计算项并解释所需方法，不能手抄未经检查的数字。

核心假设、因果关系和估值判断必须独立复核。模型假设变化传播到依赖的输出与报告，不改写旧修订。

# 研究论证与报告写作

回答问题优先：摘要说明当前判断、依据、变化与最大不确定性。正文按论证组织，避免逐工具或逐文件的流水账。每一段核心判断连接 assertion，量化内容使用 value 片段，出处使用 citation 片段。

ReportDocument 是网页和 Word 的唯一正文。段落、表格、图表中的金额、比率、增减均引用 Value；不要手抄数字或另写 Word 摘要。日期、名称等文本可以使用 text 片段。图表只表达有意义的比较，空值保留 null，预测序列明确标识。

引用要足够解释上下文，可指向原件页或块；文档标题、链接和准确版本随引用保存。支持与反证都要覆盖，来源清单不是论证。

预算不足或资料不足时仍保存有用的部分报告，在 gaps 和 next_steps 明确未完成项。不能宣称未执行的复核、Word 渲染或人类评价已经通过。旧报告只通过新修订变化。
